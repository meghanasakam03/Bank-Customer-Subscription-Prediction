# 🏦 BankInsight – Customer Intelligence Dashboard

An end-to-end Machine Learning application that predicts whether a bank customer is likely to subscribe to a term deposit.

## 🎯 Problem Statement

Predict customer term deposit subscription behaviour using demographic, financial and historical marketing campaign information.

## 📊 Input Features

- Age
- Occupation
- Marital Status
- Education
- Credit in Default
- Account Balance
- Housing Loan
- Personal Loan
- Contact Method
- Last Contact Day
- Campaign Month
- Contacts in Current Campaign
- Days Since Previous Contact
- Previous Contacts
- Previous Campaign Outcome

## 🤖 Machine Learning

- Task: Binary Classification
- Target Variable: Term Deposit Subscription
- Output: Yes or No

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Joblib
- Streamlit
- GitHub

## ✨ Application Features

- Interactive customer information form
- Professional banking dashboard
- Customer subscription prediction
- Subscription probability
- Probability breakdown chart
- Responsive user interface

## 📁 Project Files

- `app.py` — Streamlit frontend
- `logistic_model.pkl` — Trained Machine Learning model
- `requirements.txt` — Required dependencies

## 💻 Run Locally

Install dependencies:

`pip install -r requirements.txt`

Run the application:

`streamlit run app.py`
